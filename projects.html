Lean 4 / LaTeX

LeanTeX

A LaTeX package for embedding Lean 4 code directly in LaTeX and rendering Lean's infoview output in the compiled document. I made it to help with school work where formal code and ordinary mathematical exposition needed to sit closer together. A new release is expected soon.

TikZ / browser tool

GraphToTeX

A browser tool for drawing graphs and exporting clean LaTeX/TikZ code. I built it for quick school-work diagramming, when a mathematical note needs a graph more than it needs a full graphics workflow.
